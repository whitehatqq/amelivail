AMELI VAIL — сайт-визитка (одна страница)

Открыть сайт:
- index.html (картинки берутся из папки assets/img/, держите их рядом)
- variants.html — страница выбора дизайна (по 3 варианта каждого блока).
  В index.html собраны выбранные: 1B, 2A, 3B, 4B, 5C.

Где что менять (всё в index.html):
1. ТРЕКИ — в самом низу файла массив: const tracks = [...]
   title   — название
   cover   — обложка ('assets/img/...webp') или null (будет градиентная заглушка)
   link    — ссылка «Слушать полностью» (band.link и т.п.)
   preview — файл-отрывок, например 'assets/audio/serdtse.mp3'.
             Пока стоит null — играет синтезированное ДЕМО, а не песня.
   start   — с какой секунды начинать отрывок (например, с припева)
   year    — год релиза
2. Длина отрывка — константа PREVIEW_SECONDS (сейчас 30 сек).
3. Биография — блок «Об артистке» (большая фраза-манифест, сейчас текст-заглушка).
4. Почта для букинга — блок «Контакты» (сейчас booking@example.com, id="c3mail").
5. Юридический текст — в <footer>, значения в [квадратных скобках] заполнить.

Перед публичным запуском:
- удалить строку <meta name="robots" content="noindex, nofollow"> (сейчас сайт скрыт от поисковиков).
